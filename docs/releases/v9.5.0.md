## What's new in TinyTouch 9.5.0

### Before you update
**Touch projects made in 9.4.0 or earlier cannot be opened in 9.5.0.** TinyTouch refuses them and leaves the files untouched. Finish your current projects in the version you started them with. We recommend extracting 9.5.0 into a different folder and starting new projects there.

Analysis reads only exports in the current format (written by 9.3.0 and newer). Coding setup files exported before 9.3.0 can no longer be imported.

### Update notice
At startup TinyTouch asks GitHub once whether a newer release exists. If there is one, a short notice links to its release page; you can open it (TinyTouch then closes), continue with your current version, or skip that version. Nothing is downloaded or installed for you, and no data about you or your projects is sent.

### Right Foot and Left Foot
The two lower channels are now called **Right Foot** and **Left Foot** instead of Right Leg and Left Leg. The export columns (`Channel3`, `Channel4`) are unchanged.

### Pose export
Every save of a 3D Pose project now also writes two files to the video's `export/` folder:

- `<video>_pose_export.csv`: one row per frame with the zones that start and stop, body and head size (and whether each value was set by hand or carried forward), quality, the three parameters and the note.
- `<video>_pose_metadata.json`: frame rate, the coding setup with zone and parameter names, Special Zones and labeling time.

If the export cannot be written (for example the CSV is open in Excel), your labels are still saved and TinyTouch tells you the export is out of date. The format is described in [POSE_DATA_FORMAT.md](https://github.com/Humanoids-CTU/tiny-touch/blob/master/docs/POSE_DATA_FORMAT.md). Pose Analysis is not available yet; the Touch export is unchanged.

### Close without saving
Closing the app now offers **Save and close**, **Don't save** or **Cancel**. Don't save asks once more before discarding the changes made since the last save.

### Unpaired marks
Before Analysis and before closing, TinyTouch lists offsets without an onset as well as onsets without an offset, and can jump to each one.

### Pose quality
The quality rating carries forward as you step or play, like body and head size, and appears as a red-to-green band on the Pose timeline.

## Download
**Windows 10/11 (64-bit):** download **TinyTouch-v9.5.0-windows-x64.zip**, extract it into a new folder, and double-click **TinyTouch-v9.5.0.exe**.

### Linux
Linux is not supported for now. This release is Windows only; the last Linux build is [9.3.0](https://github.com/Humanoids-CTU/tiny-touch/releases/tag/v9.3.0).
